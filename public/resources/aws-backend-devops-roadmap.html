Recommended Learning Sequence

Recommended Priority

LEVEL 1
IAM, EC2, S3, RDS/PostgreSQL, VPC, CloudWatch, Docker, ECS, Fargate, ECR, ALB, Secrets Manager, SQS, Terraform, CI/CD.
LEVEL 2
Route 53, Auto Scaling, Redis, CloudFront, Lambda, API Gateway, SNS, DynamoDB.
LEVEL 3
EventBridge, Step Functions, CloudTrail, AWS WAF, KMS, AWS Organizations, Systems Manager, OpenSearch, Cognito, EKS/Kubernetes, Aurora, PrivateLink, Transit Gateway.

Target Production Architecture

Internet → Route 53 → CloudFront → ALB → ECS/Fargate Go API → RDS PostgreSQL / Redis / SQS
Supporting services: S3 for files · ECR for Docker images · Secrets Manager for credentials · CloudWatch for logs/metrics/alerts · IAM for access control · VPC for networking · Terraform for infrastructure · GitHub Actions for CI/CD.

Key Backend Pattern

Client → Go API → SQS → Worker → External Service
Decouples long-running / background work from the request-response path so the API can respond quickly.
