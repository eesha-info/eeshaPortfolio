Prisma Complete Guide

Prisma is a type-safe ORM for Node.js and TypeScript that replaces raw SQL and hand-written query builders with a single declarative schema file. You describe your tables as model blocks once, run one command, and Prisma generates a fully type-safe query client tailored exactly to that schema — autocomplete for every field and relation, compile-time errors when a query is wrong, and no raw SQL required for the vast majority of everyday queries. This doc walks through the 8 things you actually need to learn to use Prisma confidently in a real project: setup, the schema file, migrations, querying, relations, filtering/sorting/pagination, transactions, and the developer tools that make local development pleasant.

Prisma's Type-Safety Pipeline

The single most useful thing to understand about Prisma: mistakes that would normally surface as a runtime SQL error instead show up as a red squiggly line in your editor, before the code ever runs.

Diagram · Schema → Generated Types → Compile-Time Safety

A typo'd field name, a wrong relation, or a filter on a column that doesn't exist gets caught by the compiler, not by a failed query in production — the mistake never makes it past the top branch to the bottom one.
